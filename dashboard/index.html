implied value = TVL × category multiple × growth × maturity × breadth × confidence Multiples are medians of mcap/TVL per category, winsorized at 3× and shrunk toward the global median (0.214) with prior weight 5 — so one observation never sets a multiple alone.

How the value is built

  • Category multiple — median mcap/TVL of the token-bearing protocols in the category, winsorized at 3×, shrunk toward the global median 0.214 with prior weight 5, clamped 0.05–1.50.
  • Growth — 1 + 7-day TVL change, clamped to ±30%. Unreported change counts as 1.00.
  • Maturity — 0.85 + 0.15 × min(age in years ÷ 3, 1). Protocols with no listing date count as 0.925.
  • Breadth — 1 + 0.05 per extra chain, up to 1.20.
  • Confidence — 1.00 when a category has 5+ token observations, 0.97 for 2–4, 0.92 for 1, 0.88 for none. The discount is the model admitting what it does not know.

The watchlist is the house rule: TVL ≥ $50M, no token recorded, not a wrapped, staked, bridged, versioned or exchange product. The board holds all 198 genuine candidates in the snapshot — the 40 on the watchlist plus the 158 below the floor. An implied value is this entry's own claim, never a promise that a token launches or what it will trade at.
