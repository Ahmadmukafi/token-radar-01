Token Launch Radar

Every protocol in the snapshot that records no token and is not a wrapped, staked or bridged product of one that already trades — ranked by what its token would be worth if it launched one day, on the snapshot’s own figures.

How the value is computed

implied value = TVL × category multiple × growth × maturity × breadth

Category multiple

For each category, the median market-cap / TVL of the token-bearing protocols in that category — each protocol’s ratio winsorized at 3×, so one tiny-TVL token cannot set a category — shrunk toward the global median () with a prior weight of 3, clamped to 0.05–1.50. A category with no token-bearing protocol uses the global median. The multiples are computed from this snapshot, not written in by hand.

Growth · maturity · breadth

Growth = 1 + 7-day TVL change / 200, clamped to 0.70–1.30. Maturity = 1 + 0.4 × min(age in days, 730) / 730: a protocol that has run two years with no token scores up to 1.40. Breadth = 1 + 0.02 × min(chains − 1, 15): more chains, wider reach.

Who is not ranked, and why

A protocol whose token already trades has no launch left to value. A wrapped, staked or bridged product (WBTC is Bitcoin on Ethereum) is not a protocol waiting on a launch of its own. Centralised exchanges and versioned copies are out for the same reason. The board is the 198 protocols that pass that filter.
